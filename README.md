# Gate 4–5 · Данные, модель и оценка продукта удержания клиентов РКО

Учебный проект по управлению продуктами машинного обучения, кейс B: прогноз оттока → действие → контрольная группа. Все данные сгенерированы, банк условный.

## Результат

- Рекомендация: **Pivot, к релизу не готов**.
- Precision@10% реального ухода: **5,6% против 2,5%** у правил; lift 3,00.
- 37% меток «тихий отток» оказались не уходом, а сезонной спячкой; на официальном таргете модель выглядит вдвое лучше, чем есть.
- 12-месячный эффект оффера **0,91 п.п.** при пороге окупаемости 20,47 п.п.; **0,10 ₽** на 1 ₽ бюджета при цели 3 ₽.
- Критические сценарии 21 из 21, основные 12 из 17; red-team закрыт на 4 из 10.

## Запуск

Требуется Python 3.12; около 10 минут и 8 ГБ памяти.

```sh
sh run.sh
```

Команда создаёт окружение, пересобирает панель, модели, разметочные метрики, эвалы и ноутбук, запускает тесты. Панель и модели в Git не хранятся и воспроизводятся этой командой. Просмотр результатов запуска не требует: документ, ноутбук и `results/` читаются сразу.

## Карта репозитория

| Путь | Содержание |
|---|---|
| `src/generator.py` | Панель v2, скрытые драйверы и потенциальные исходы |
| `src/models.py`, `src/experiment.py` | Модели, сравнение, срезы, политики, экономика |
| `src/service.py` | Гардрейлы и решение по клиенту |
| `src/evals.py` | Eval-сет и red-team |
| `src/labeling.py` | Каппа и бейзлайн на размеченных данных |
| `src/analysis.py` | Разведочный анализ, не входил в предрегистрацию |
| `labeling/` | Случаи, гайдлайн, метки обоих проходов |
| `results/` | Все метрики в JSON |

Лицензионных ограничений на данные нет: все данные созданы для проекта и не содержат персональных сведений.

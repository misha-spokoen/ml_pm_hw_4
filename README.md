# ДЗ #4 — Gate 4–5: Data, Modeling & Evaluation

Сквозной кейс B «отток → удержание», табличный ML. Продукт — внутренний сервис next-best-action для команды удержания МСБ: прогноз оттока клиента РКО → действие → контрольная группа. Продолжение Gate 2–3, Gate 3 сдан, результат проверки ещё не получен.

**[Основной документ](gate45-data-evaluation.md)** содержит ответы на блоки A–I, Data Plan, самооценку и рекомендацию. Эта страница помогает оценить работу по критериям задания.

> **Происхождение данных.** Проект учебный. Панель клиентов, случаи разметки и эффекты офферов полностью сгенерированы, банки условные. Разметку выполнил Claude, люди не участвовали. Метрики — реальные результаты запуска кода, они проверяют метод и логику продукта, а не поведение реальных клиентов.

## Итог

**Рекомендация: Pivot, к релизу не готов.** Сервис находит реальный уход вдвое лучше правил и безопасен в критических сценариях, но экономика не сходится.

| Вопрос | Результат | Цель |
|---|---:|---:|
| Лучше ли правил? Precision@10% реального ухода | **5,6% против 2,5%** | +20% к правилам |
| Хватает ли охвата? Lift@10% реального ухода | **2,997** | ≥ 3,0 |
| Честен ли таргет? Меток «тихий отток» без реального ухода | **36,8%** | Нет порога; новая находка |
| Окупается ли действие? 12-месячный эффект оффера | **0,91 п.п.** | ≥ 20,47 п.п. |
| Метрика успеха продукта: выручка на 1 ₽ бюджета | **0,10 ₽** | ≥ 3 ₽ |
| Критические сценарии eval-сета | **21 из 21** | 100% |
| Основные сценарии eval-сета | **12 из 17** | ≥ 90% |
| Согласованность разметки, каппа Коэна | **0,90 и 0,98** | ≥ 0,70; верхняя оценка |

Главные находки:

- На официальном таргете модель выглядит вдвое сильнее, чем есть: precision 13,7%, lift 4,65. Она выбирает клиентов с сезонной спячкой.
- Самое слабое звено — цена действия, а не ML: даже идеальный отбор находит лишь 0,45% клиентов, у которых оффер окупается.
- На отобранных клиентах контакт чаще вредит, чем помогает: вред 1,45% против пользы 0,97%, n=207.

Продолжать стоит с действием дешевле ≈630 ₽ на обработанного клиента, на верхнем 1% по риску × выручке и с сезонной поправкой таргета. [Условия возврата к решению о пилоте](gate45-data-evaluation.md#часть-4-рекомендация).

## Как проверить

Без запуска, около 15 минут:

1. [Основной документ](gate45-data-evaluation.md): начать с итога в первых строках, затем [I1](gate45-data-evaluation.md#i1-чек-лист-go--no-go) и [рекомендацию](gate45-data-evaluation.md#часть-4-рекомендация).
2. [Ноутбук](notebooks/baseline.ipynb): метрики и таблицы со значениями.
3. [Eval-сет](eval/eval_set.csv) и [red-team](eval/redteam.csv): фильтр по `passed = False` показывает, что не пройдено.
4. [Предрегистрация](preregistration.md): пороги и поправки.

Честность порогов можно проверить по истории: [пороги](https://github.com/misha-spokoen/ml_pm_hw_4/commit/33a17c0) и [код](https://github.com/misha-spokoen/ml_pm_hw_4/commit/290f1ba) закоммичены раньше [результатов](https://github.com/misha-spokoen/ml_pm_hw_4/commit/86f0bc5). Изменения, сделанные после просмотра результатов, перечислены в [поправках](preregistration.md#6-поправки).

Первичные метрики: [основной запуск](results/main.json), [чувствительность](results/sensitivity.json), [разведочный анализ](results/analysis.json), [разметка](results/labeling.json), [сводка эвалов](results/evals.json).

## Запуск

Нужны Python 3.12, около 10 минут и 8 ГБ памяти:

```sh
sh run.sh
```

Команда создаёт окружение, пересобирает панель, модели, метрики разметки, эвалы и ноутбук, запускает тесты. Панель и модели в Git не хранятся и воспроизводятся этой командой. Повторный запуск дал те же значения метрик. Интернет нужен только для установки библиотек.

## Ограничения

- Реальных данных, клиентов, кампаний и интервью нет. Эффект оффера и доля принявших его — допущения симуляции.
- Каппа получена на двух проходах одного агента. Настоящую согласованность покажет только второй человек.
- Онлайн-эвалы и A/B спроектированы, но не запускались.
- Предусловие «принятый Gate 3» не подтверждено: результат проверки ещё не получен.
